Preliminary: Regular Decoding Strategies

Greedy Search 在每个时间步 ttt 从词汇表 V\mathcal{V}V 中选择条件概率最高的 token，公式如下：

yt=arg⁡max⁡y∈Vp(y∣x,y<t)y_{t}=\arg\max_{y \in \mathcal{V}} p(y \mid \mathbf{x},\mathbf{y}_{<t}) yt​=argy∈Vmax​p(y∣x,y<t​)

该确定性方法虽然计算高效，但由于仅考虑当前局部最优 token，可能无法得到全局最优序列。为缓解该局限性，Top-kkk Sampling 通过限制候选集大小引入随机性，在每个时间步 ttt 仅从概率最高的 kkk 个 token 中采样，公式如下：

yt∼arg⁡topk⁡y∈Vp(y∣x,y<t)y_{t} \sim \operatorname*{\arg topk}_{y \in \mathcal{V}} p(y \mid \mathbf{x},\mathbf{y}_{<t}) yt​∼y∈Vargtopk​p(y∣x,y<t​)

另一类方法称为 Beam Search，在每个时间步 ttt 都维护概率最高的 kkk (beam width) 个候选序列，最终选择概率最高的生成响应。在时间步 ttt，对每个已生成的序列 y<t∈Bt−1\mathbf{y}_{<t} \in \mathcal{B}_{t-1}y<t​∈Bt−1​，计算扩展 token yyy 后的序列得分：

s(y<t,y)=log⁡p(y<t,y∣x)s(\mathbf{y}_{<t},y) = \log p(\mathbf{y}_{<t},y \mid \mathbf{x}) s(y<t​,y)=logp(y<t​,y∣x)

其中，Bt−1\mathcal{B}_{t-1}Bt−1​ 是 t−1t-1t−1 时刻得分最高的 kkk 个句子集合，s(y<t,y)s(\mathbf{y}_{<t},y)s(y<t​,y) 是序列 [y<t,y][\mathbf{y}_{<t},y][y<t​,y] 的优化目标，通常定义为累计对数概率。接着，选择 ttt 时刻得分最高的 kkk 个序列，更新集合 Bt\mathcal{B}_{t}Bt​：

Bt=arg⁡topk⁡y<t∈Bt−1,y∈Vs(y<t,y)\mathcal{B}_{t}= \operatorname*{\arg topk}_{\mathbf{y}_{<t} \in \mathcal{B}_{t-1}, y \in \mathcal{V}} s(\mathbf{y}_{<t},y) Bt​=y<t​∈Bt−1​,y∈Vargtopk​s(y<t​,y)

Vanilla Contrastive Decoding

对比解码（Contrastive Decoding）的思想最初源于 [1] 这一工作，要点归纳如下：

  • 目的：提高开放性任务的文本质量，包括：提高多样性、流畅性、连贯性，减少重复性等
  • 动机：语言模型（Language Models, LMs）的许多失效模式（如重复性、不连贯性）在小规模的 LMs 中比较大的 LMs 中更常见，可以利用二者的差异来弱化此类输出
    • 专家模型（Expert LM）：一个参数规模较大的 LM，具有更强的语言生成能力
    • 业余模型（Amateur LM）：一个参数规模较小的 LM，更易出现重复、不连贯等问题
  • 方法：
    • 计算 large expert LM 与 small amateur LM 的对数概率之差，作为 Beam Search 的优化目标（Vanilla Beam Search 的优化目标定义为累计对数概率）
    • 为了确保生成的文本在专家模型下仍然合理，引入自适应合理性约束（Adaptive Plausibility Constraint, APC），限制候选词范围，仅保留在专家模型下概率足够高的词

APC 的公式如下：

Vvalid(x,y<t)={y∈V:pexp(y∣x,y<t)≥αmax⁡ω∈Vpexp(ω∣x,y<t)}\mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t}) = \big\{ y \in \mathcal{V} : p_{\text{exp}}(y \mid \mathbf{x},\mathbf{y}_{<t}) \geq \alpha \max_{\omega \in \mathcal{V}}p_{\text{exp}}(\omega \mid \mathbf{x}, \mathbf{y}_{<t}) \big\} Vvalid​(x,y<t​)={y∈V:pexp​(y∣x,y<t​)≥αω∈Vmax​pexp​(ω∣x,y<t​)}

其中：

  • Vvalid(x,y<t)\mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t})Vvalid​(x,y<t​): APC 过滤后的有效候选 token 集合
  • pexp(y∣x,y<t)p_{\text{exp}}(y \mid \mathbf{x}, \mathbf{y}_{<t})pexp​(y∣x,y<t​): 专家模型的 next token 条件概率
  • max⁡ωpexp(ω)\max_{\omega}p_{\text{exp}}(\omega)maxω​pexp​(ω): 当前时间步专家模型中概率最高 token 的概率值
  • α∈[0,1]\alpha \in [0, 1]α∈[0,1]: 控制约束程度的超参数

APC 通过每个时间步动态自适应计算 αmax⁡ωpexp(ω)\alpha \max_{\omega}p_{\text{exp}}(\omega)αmaxω​pexp​(ω) 这一相对比例，过滤了专家模型中概率较小的候选词。而对于保留下来的概率较高的候选词（即：Vvalid(x,y<t)\mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t})Vvalid​(x,y<t​) 中的 token），需要进一步计算专家业余模型的对数概率之差。最终，给出 Beam Search 的优化目标：

s(y∣x,y<t)={log⁡pexp(y∣x,y<t)−log⁡pama(y∣x,y<t),if y∈Vvalid(x,y<t),−∞,otherwise.\begin{aligned} s(y \mid \mathbf{x}, \mathbf{y}_{<t}) = \begin{cases} \log p_{\text{exp}}(y \mid \mathbf{x}, \mathbf{y}_{<t})-\log p_{\text{ama}}(y \mid \mathbf{x}, \mathbf{y}_{<t}), & \text{if~}y \in \mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t}), \\ -\infty, & \text{otherwise.} \end{cases} \end{aligned} s(y∣x,y<t​)={logpexp​(y∣x,y<t​)−logpama​(y∣x,y<t​),−∞,​if y∈Vvalid​(x,y<t​),otherwise.​​

Note

原论文中，使用 Beam Search 来进行解码。事实上，这里的 s(y∣x,y<t)s(y \mid \mathbf{x}, \mathbf{y}_{<t})s(y∣x,y<t​) 可以进一步 softmax 归一化得到概率分布，使用 sampling-based 方法进行采样解码。

图中的专家业余模型分别为 GPT-2 XL 与 GPT-2 small。给定同一输入 prompt，两个模型分别计算 next token 的概率分布，再计算对比解码的分数。首先人工分析我们期待的模型输出，由于输入 prompt 已经给出了 Obama 出生的地区，显然我们不想让模型重复输出这一已知信息。

  • 如果直接采取 Greedy Search，模型将陷入无限重复，文本生成质量较差；
  • 如果采取 Nucleus Sampling，模型给出了错误答案 Washington, D.C；
  • 如果采取对比解码，模型将输出 Obama 的出生年份 1961，这一续写既准确又多样。

我们归纳对比解码的两个核心组件：一个是 APC，另一个是优化目标的定义。后续的大量工作，也是针对这两个组件进行改进。一个典型的工作是 [2]，该工作将对比解码扩展至推理任务中，我们重点关注其对于 [1:1] 的改进。

Faithfulness-Enhanced Contrastive Decoding

CAD: Context-Aware Decoding[3]

如上图所示，红蓝色框分别表示有无上下文时的解码：

  • 当无上下文时，模型根据过时的先验知识，错误地判断 Argentina 只赢得两届世界杯；
  • 当有上下文时，上下文与先验知识发生冲突，虽然正解 Three 的 预测 logit 变高，但仍然小于错解 Two。

CAD 通过对比有无上下文的预测，放大对上下文的关注，抑制错误先验知识的影响，从而使得正解 Three 的 logit 最高。归纳 CAD 的要点如下：

  • 动机：在 NLG 中，LMs 主要依赖两种知识：1）先验知识：预训练阶段学习到的隐式知识，存储于模型参数中；2）上下文知识：输入的用户查询或文档提供的新信息。然而，当前的 LMs 在生成时可能过度依赖先验知识，而对输入上下文中的新信息关注不足，尤其是在上下文知识与先验知识存在冲突时。
  • 方法：对比有无上下文时的预测 logits 并进行调整，具体来说：
    • 如果某一 token 在有上下文时比无上下文时的 logits 提高很多，则相对更易被采样
    • 如果某一 token 主要依赖先验知识（即上下文对它的影响不大），则相对更难被采样

对比解码优化目标定义如下：

s(y∣c,x,y<t)=(1+β)l(y∣c,x,y<t)−βl(y∣x,y<t)s(y \mid \mathbf{c}, \mathbf{x}, \mathbf{y}_{<t}) = (1+\beta) \mathbf{l}(y \mid \mathbf{c}, \mathbf{x}, \mathbf{y}_{<t}) - \beta \mathbf{l}(y \mid \mathbf{x}, \mathbf{y}_{<t}) s(y∣c,x,y<t​)=(1+β)l(y∣c,x,y<t​)−βl(y∣x,y<t​)

其中，c\mathbf{c}c 表示为查询的文档，β\betaβ 用于控制对比强度。当 β=0\beta = 0β=0 时，退化为标准采样。

对比 [2:2]，可以看到优化目标定义形式非常相似，区别在于去除了 APC 这一组件。

Factuality-Enhanced Contrastive Decoding

ICD: Induce-then-Contrast Decoding[4]

如上图所示，ICD 的核心思想在于：

  1. 诱导幻觉：利用非事实样本直接微调原始模型，从中诱导出一个 " 事实性较弱 " 的幻觉模型（Weak LLM），使其更倾向于产生幻觉
  2. 对比解码：将诱导出的幻觉模型的输出作为 " 惩罚项 "，与原始模型的输出进行对比，从而抑制幻觉内容的生成，增强原始模型高事实性的预测。

对于微调的细节我们不做讨论，我们重点关注对比解码这一核心思想。对比解码优化目标定义如下：

s(y∣x,y<t)=βlog⁡pexp(y∣x,y<t)−log⁡pama(y∣x,y<t)s(y \mid \mathbf{x}, \mathbf{y}_{<t}) = \beta \log p_{\text{exp}}(y \mid \mathbf{x}, \mathbf{y}_{<t}) - \log p_{\text{ama}}(y \mid \mathbf{x}, \mathbf{y}_{<t}) s(y∣x,y<t​)=βlogpexp​(y∣x,y<t​)−logpama​(y∣x,y<t​)

其中，pexp(⋅),pama(⋅)p_{\text{exp}}(\cdot), p_{\text{ama}}(\cdot)pexp​(⋅),pama​(⋅) 分别为原始（专家）模型与幻觉（业余）模型的概率分布，β∈(0,+∞)\beta \in (0, +\infty)β∈(0,+∞) 用于控制对比强度。此外，采取 APC 限制候选词范围：

Vvalid(x,y<t)={y∈V:lexp(y∣x,y<t)≥αmax⁡ωlexp(ω∣x,y<t)}\mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t}) = \big\{ y \in \mathcal{V} : \mathbf{l}_{\text{exp}}(y \mid \mathbf{x}, \mathbf{y}_{<t}) \geq \alpha \max_{\omega}\mathbf{l}_{\text{exp}}(\omega \mid \mathbf{x}, \mathbf{y}_{<t}) \big\} Vvalid​(x,y<t​)={y∈V:lexp​(y∣x,y<t​)≥αωmax​lexp​(ω∣x,y<t​)}

对比 [2:3]，APC 形式完全一致，区别在于优化目标中，对比强度 β\betaβ 系数的调整。

DoLa: Decoding by Contrasting Layers[5]

过去对模型可解释性的相关研究表明，Transformer LMs 的较早层（较低层）更多地编码 “lower-level” 信息（e.g., POS tags），较晚层（较高层）则更多地编码 " 语义 " 信息。可通过对比较晚层和较早层的输出差异，来增强模型生成内容的事实性。

上图展示了 LLM 自底向上逐层融入事实信息的过程。具体来说，对 LLaMA-7B 的所有中间层都应用 early exit，即为所有中间层的隐藏态都添加 LM 预测头，从而得到每一层的 next token probability。由图可知，“Seattle” 在每层的概率都维持在较高水平，可能由于这是个在语法上合理的答案；而正解 “Olympia” 的概率随着 LLM 事实知识的逐层增加而逐渐增大。因此，对比不同层的预测可能揭示出正确答案。随之而来的问题是，如何选择对比层？

假设模型共有 NNN 层 transformer decoder layer (i.e., multi-head attention layer + feed-forward network layer)，第 000 层是 embedding layer。DoLa 选定最顶部的第 NNN 层作为 mature layer (对应于对比解码中的 expert layer)，接着从 0,1,…N−10, 1, \ldots N-10,1,…N−1 层中选择一个 premature layer (对应于对比解码中的 amateur layer) 进行对比。假设最终选定的 premature layer 为第 MMM 层 (0≤M<N)(0 \leq M < N)(0≤M<N)，则最终的 next token score 如下：

s(y∣x,y<t)={log⁡pN(y∣x,y<t)−log⁡pM(y∣x,y<t),if y∈Vvalid(x,y<t),−∞,otherwise.\begin{aligned} s(y \mid \mathbf{x}, \mathbf{y}_{<t}) = \begin{cases} \log p_{N}(y \mid \mathbf{x}, \mathbf{y}_{<t}) - \log p_{M}(y \mid \mathbf{x}, \mathbf{y}_{<t}), & \text{if~}y \in \mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t}), \\ -\infty, & \text{otherwise.} \end{cases} \end{aligned} s(y∣x,y<t​)={logpN​(y∣x,y<t​)−logpM​(y∣x,y<t​),−∞,​if y∈Vvalid​(x,y<t​),otherwise.​​

此外，采取与对比解码类似的 APC：

Vvalid(x,y<t)={y∈V:pN(y∣x,y<t)≥αmax⁡ω∈VpN(ω∣x,y<t)}\mathcal{V}_{\text{valid}}(\mathbf{x}, \mathbf{y}_{<t}) = \big\{ y \in \mathcal{V} : p_{N}(y \mid \mathbf{x},\mathbf{y}_{<t}) \geq \alpha \max_{\omega \in \mathcal{V}}p_{N}(\omega \mid \mathbf{x}, \mathbf{y}_{<t}) \big\} Vvalid​(x,y<t​)={y∈V:pN​(y∣x,y<t​)≥αω∈Vmax​pN​(ω∣x,y<t​)}

在每个解码步，premature layer 通过动态比较最顶层（第 NNN 层）与候选层（0,1,…N−10, 1, \ldots N-10,1,…N−1 层）的 Jensen-Shannon Divergence (JSD) 而确定。JSD 是一种衡量两个概率分布之间差异的距离指标，DoLa 希望选定的 premature layer 的预测分布与最顶层的差异最大，也就是 JSD 最大。如果某层的输出与最顶层差异很大，可能说明从该层到最顶层，模型的预测发生了显著调整。这种调整可能意味着模型在后续层中加入了新的信息，修正了之前的预测。因此，为了放大该层之后涌现出的知识，DoLa 选择与最顶层间 JSD 最大的 premature layer：

M=arg⁡max⁡j∈JDJS(pN(⋅∣x,y<t)∥pj(⋅∣x,y<t))M = \arg\max_{j \in \mathcal{J}} \mathbb{D}_{\text{JS}}(p_{N}(\cdot \mid \mathbf{x}, \mathbf{y}_{<t}) \| p_{j}(\cdot \mid \mathbf{x}, \mathbf{y}_{<t})) M=argj∈Jmax​DJS​(pN​(⋅∣x,y<t​)∥pj​(⋅∣x,y<t​))

其中，J⊂{0,1,…,N−1}\mathcal{J} \subset \{0,1, \ldots, N-1 \}J⊂{0,1,…,N−1} 为候选 premature layer 集合。

Safety-Enhanced Contrastive Decoding

SafeDecoding: Safety-Aware Decoding[8]

SafeDecoding 与 ICD[4:1] 类似，都是先构造对比模型，再对比新模型与原始模型的 next token 概率分布进行解码。区别在于前者构造的是专家模型（安全模型），而后者构造的是业余模型（幻觉模型）。如上图所示，SafeDecoding 分为两个阶段：

  1. 训练阶段：构建专家模型
    • 查询收集：收集 36 个有害查询，涵盖 18 个有害类别。这些查询应被任何与人类价值对齐的 LLM 所拒绝。
    • 响应生成与筛选：使用原始模型对这些有害查询生成响应，然后通过 GPT-4 过滤，保留那些有效拒绝有害查询的响应，构建微调数据集。
    • 模型微调：使用参数高效微调方法（e.g., LoRA）对原始模型进行微调，得到专家模型，使其更擅长识别和拒绝恶意用户输入。
  2. 推理阶段：构建新的 token 分布
    • 构造样本空间：在每个解码步，分别通过原始模型和专家模型得到 top-k 的 token 集合，取二者交集作为新的样本空间，平衡原始模型的有用性与专家模型的安全性。
    • 定义概率函数：基于原始模型和专家模型的概率分布，构造新的概率函数，放大对齐人类价值的 token 概率，抑制符合攻击者目标的 token 概率。
    • 采样生成响应：根据新构造的概率分布采样 next token，生成对输入查询的响应。

在推理阶段，样本空间的构造公式如下：

  • Vk\mathcal{V}^{k}Vk, V′k\mathcal{V}^{\prime k}V′k: 在当前解码时间步，原始模型与专家模型输出的 top kkk 个最可能 token 的集合。

ROSE: Reverse prOmpt contraStive dEcoding[9]

ROSE 的对比解码优化目标如下：

s(y∣s,x,y<t)=l(y∣s,x,y<t)−βl(y∣s^,x,y<t)s(y \mid \mathbf{s}, \mathbf{x}, \mathbf{y}_{<t}) = \mathbf{l}(y \mid \mathbf{s}, \mathbf{x}, \mathbf{y}_{<t}) - \beta \mathbf{l}(y \mid \hat{\mathbf{s}}, \mathbf{x}, \mathbf{y}_{<t}) s(y∣s,x,y<t​)=l(y∣s,x,y<t​)−βl(y∣s^,x,y<t​)

其中，β\betaβ 用于控制对比强度，s\mathbf{s}s 为安全的系统提示，s^\hat{\mathbf{s}}s^ 为精心设计的反向系统提示（Reverse System Prompts）。ROSE 的核心在于反向提示 s^\hat{\mathbf{s}}s^ 的设计，以下是提出的几种设计变体：

  • Rand-Words (Rand): 直接让第三方 LLMs 随机替换原提示 s\mathbf{s}s 的词汇
  • Opposite-Replace (Replace): 替换关键的正面词汇为相应的反面词汇
  • Manual-Reverse (Manual): 人工手动重写（或第三方 LLMs 重写）原提示 s\mathbf{s}s，使其更流畅易懂

Comparison and Contrast

前文详细介绍了多种基于对比解码思想的改进策略，它们分别从不同角度（如提升忠实性、事实性、安全性等）对 Vanilla Contrastive Decoding 进行了扩展和优化。为了更清晰地展现这些方法之间的异同，本节将从多个维度对它们进行归纳和比较。

在下方的表格中，我们总结了本文讨论的各种对比解码策略的关键特性。各列含义如下：

  • Method: 对比解码策略的名称
  • Enhancement Focus: 该方法主要致力于提升生成文本的哪方面质量或能力（例如：事实性、安全性、推理能力、通用文本质量等）。
  • APC Presence: 该方法是否采用了 APC
  • Contrast Formulation: 对比解码中优化目标的数学基础，即该分数是基于（对数）概率还是基于 logits 等
  • Contrast Level: 对比的层次。可能是不同模型间的对比（Inter-Model），也可能是在单个模型内部通过改变输入、内部状态（如不同层）或提示进行的对比（Intra-Model）。
  • Expert Component: 在对比解码中充当 " 专家 " 角色的组件（模型/层）。通常，这是希望其特性得到增强或保留的组件
  • Amateur Component: 在对比解码中充当 " 业余 " 角色的组件。通常，这是希望其不期望特性得到抑制的组件
  • Training Free: 该方法本身是否需要对 LM 进行额外的训练或微调
