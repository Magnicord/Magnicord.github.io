Examples

PyTorch

在安装 flash-attn 前，我们先分析 torch 的安装配置。torch 常见的版本有 cuda 版与 cpu 版，当我们直接使用 pip install torch 时，会从 pypi 进行索引，默认下载的是 cpu 版。PyTorch 官方提供了自己的 index url:

  • cpu: https://download.pytorch.org/whl/cpu
  • cuda: https://download.pytorch.org/whl/cu128

这里 cuda 版本的 index url 后缀是版本名，可以根据自身 cuda 版本进行修改，例如：

  • cuda118: https://download.pytorch.org/whl/cu118
  • cuda126: https://download.pytorch.org/whl/cu126
  • cuda129: https://download.pytorch.org/whl/cu129
