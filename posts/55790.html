LoRA: From Principle to Implementation

Created2025-01-19|Updated2025-03-05|NLP
|Word Count:734|Reading Time:4mins|Post Views:

LoRA (Low-Rank Adaptation) is a parameter-efficient fine-tuning (PEFT) technique designed to reduce the number of trainable parameters in LLMs while maintaining high performance. It achieves this by decomposing weight updates into low-rank matrices, significantly reducing memory and computational costs.

Motivation: Intrinsic Dimension Hypothesis

The Intrinsic Dimension Hypothesis states that high-dimensional models actually lie on a much lower-dimensional subspace. Similarly, LoRA hypothesizes finetuning a LLM requires only modifying a small subset of parameters or searching within a low-rank space.

Approach: Low-Rank Decomposition

Standard Full Fine-Tuning

Given a pretrained LLM, consider a weight matrix W∈Rdin×dout\mathbf{W} \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}W∈Rdin​×dout​. FFT (full fine-tuning) updates this matrix as:

W←W+ΔW\mathbf{W} \gets \mathbf{W} + \Delta \mathbf{W} W←W+ΔW

where ΔW\Delta \mathbf{W}ΔW is the update learned through gradient descent. Since W\mathbf{W}W is typically large in LLMs, storing and computing ΔW\Delta \mathbf{W}ΔW is expensive.

LoRA Approximation

LoRA constrains the update ΔW\Delta \mathbf{W}ΔW within a low-rank space as:

ΔW=BA\Delta \mathbf{W} = \mathbf{B} \mathbf{A} ΔW=BA

where A∈Rdin×r\mathbf{A} \in \mathbb{R}^{d_{\text{in}} \times r}A∈Rdin​×r, B∈Rr×dout\mathbf{B} \in \mathbb{R}^{r \times d_{\text{out}}}B∈Rr×dout​ and the rank r≪min⁡(din,dout)r \ll \min(d_{\text{in}}, d_{\text{out}})r≪min(din​,dout​).

Thus, instead of updating a full ΔW∈Rdin×dout\Delta \mathbf{W} \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}ΔW∈Rdin​×dout​, only two smaller matrices A\mathbf{A}A and B\mathbf{B}B need to be updated.

LoRA Forward Pass

In LoRA, the adapted weight matrix is:

W←W+αrBA\mathbf{W} \gets \mathbf{W} + \frac{\alpha}{r} \mathbf{B} \mathbf{A} W←W+rα​BA

where α\alphaα is a scaling factor to control the magnitude of adaptation:

  • Small α\alphaα: Tend to retain more of the pretrained knowledge
  • Large α\alphaα: Tend to learn features of new tasks
  • α/r\alpha / rα/r: Ensure that update magnitudes remain stable across different choices of rrr
